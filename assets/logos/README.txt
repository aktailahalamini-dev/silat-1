=== CARA PASANG LOGO ===
Cukup COPY file logo ke folder ini dengan NAMA PERSIS seperti di bawah (huruf kecil, ekstensi .png).
Kotak logo sudah disiapkan; gambar otomatis pas di tengah kotak. Tidak perlu mengubah kode.

  event-logo.png  -> logo utama event      (tengah, halaman utama / pilih arena / login)   disarankan 512 x 512 px
  logo-left.png   -> logo kiri             (halaman utama, bar atas, papan skor kiri)       disarankan 512 x 512 px
  logo-right.png  -> logo kanan            (halaman utama, papan skor kanan)                disarankan 512 x 512 px
  logo-tps.png    -> logo panitia/TPS      (bar atas halaman Loting)                        disarankan 256 x 256 px

Tips: pakai PNG berlatar TRANSPARAN, bentuk persegi (kotak). Logo yang tidak persegi tetap muat (tidak gepeng).
Jika file belum ada, tampil lingkaran putus-putus bertanda L / M / TPS sebagai penanda.
Ukuran kotak logo bisa diubah di css/theme.css (bagian "UKURAN LOGO" paling atas).
